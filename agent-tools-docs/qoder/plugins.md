**插件（Plugin）** 是 Skill、MCP、Agent、Command、Rule、Hook 的任意组合套件。通过安装插件，可为 Qoder 一次性引入一组协作能力，覆盖从编码、测试到部署的研发全链路。

## [​](#插件组件) 插件组件

一个插件可以打包以下组件的任意组合：

| 组件 | 描述 |
| --- | --- |
| **Skills** | 面向复杂任务的特定智能体能力 |
| **MCP Servers** | 连接外部服务的 Model Context Protocol 集成 |
| **Agents** | 可被主 Agent 调度执行特定任务的子代理 |
| **Commands** | 斜杠命令，用户手动触发的快捷操作 |
| **Rules** | 注入 AI 上下文的行为与风格约束 |
| **Hooks** | 在特定事件节点自动执行的脚本 |

## [​](#插件市场) 插件市场

在 Quest 的左侧导航底部点击**插件市场**，或在 Qoder 设置的**插件**面板右上角点击**插件市场**链接，均可进入。

### [​](#发现与浏览) 发现与浏览

市场按分类组织插件，帮助你快速找到所需能力：

| 分类 | 说明 |
| --- | --- |
| **Featured** | 编辑精选的热门插件 |
| **Coding** | 代码开发相关工具 |
| **DataBase** | 数据库操作与管理工具 |
| **Workflow** | 工作流编排与自动化 |
| **DevOps** | 部署、CI/CD 与运维工具 |
| **Product Design** | 产品设计与原型工具 |
| **Debug & Testing** | 调试与测试辅助工具 |

每个插件卡片展示名称、简介、作者、下载量和安装状态。右上角的**搜索插件**框支持按关键词快速检索。你也可以通过标签和安装状态筛选。
点击插件卡片进入详情页，可查看：

* **组件列表** — 该插件包含的 Skill、MCP、Agent、Command、Rule、Hook
* **插件信息** — 分类标签、开发者、最近更新时间、源代码地址

### [​](#安装插件) 安装插件

安装插件时，你可以选择生效范围：

* **User 级** — 对你所有会话生效
* **Project 级** — 仅在指定项目中生效

插件作为整体安装，不支持仅安装其中部分组件。安装后的插件在 Editor 和 Quest 中均可使用。

## [​](#自定义插件) 自定义插件

### [​](#创建插件) 创建插件

点击市场右上角的 **+ 创建插件**，系统会跳转到 Chat 区并自动选中内置的 `plugin-creator` Skill，通过对话引导你创建自定义插件。

### [​](#导入插件) 导入插件

你可以将本地已有的插件导入 Qoder。点击 **+ 创建插件**后选择从本地文件夹导入。

## [​](#使用插件) 使用插件

插件安装后，有以下方式调用：

* **自动触发** — 描述需求时，Qoder 会自动判断并调用匹配的插件能力
* **斜杠命令** — 在对话输入框中输入 `/插件名`，直接指定使用某个插件
* **试用** — 在插件卡片上点击 **Try now**，启动与 Agent 的会话测试插件功能

## [​](#管理插件) 管理插件

你可以通过以下入口管理插件：

* 插件市场右上角 → 点击**管理**进入管理页面
* 插件市场左侧分类底部 → 点击**已安装**筛选已安装的插件
* Qoder 设置 → 打开**插件**面板集中管理

Editor 和 Quest 的 Qoder 设置中都有插件面板，操作方式一致。

Qoder 设置的插件面板按**用户级** / **项目级**分 Tab 展示，**自定义**区域底部提供**导入**和 **+ 新建**按钮。面板右上角的**插件市场**链接可直接跳转到市场。
禁用插件后，其包含的所有组件将同时被禁用，无需逐一操作。

### [​](#组件关联) 组件关联

来自插件的组件（如 Skill、MCP、Agent 等）在各自的设置面板中会标记来源插件。这些组件由插件统一管理——不支持单独禁用、删除或修改，需要通过所属插件进行操作。
